# Release Readiness Audit

Base release readiness on evidence.

- Confirm intended commit, clean branch state, version consistency, changelog, license and release notes.
- Require applicable tests, type checks, lint, formatting, security checks and production builds.
- Verify artifact names, formats, architectures, checksums, assets, signing and provenance.
- Distinguish CI build success from installation/launch testing on each target.
- Record every waiver, untested target, warning and manual follow-up.
- Tagging, publishing, signing and uploading require owner authorization.
